# Château Grand Cru — Luxury Wine Selling E-Commerce

A luxury, high-end fine wine and rare vintage e-commerce web application built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🍇 Key Features

1. **Age Verification Modal (21+)**:
   - Legal age compliance modal adhering to wine e-commerce standards with persistence.

2. **Luxury Visual Presentation**:
   - Deep burgundy/wine palette (`#4a0e17`, `#722F37`), warm champagne gold accents (`#d4af37`), and glassmorphism styling.
   - Editorial serif typography pairing (*Playfair Display* and *Plus Jakarta Sans*).

3. **Curated Fine Wine Catalog**:
   - Real estate portfolio of iconic wines: Premier Grand Cru Bordeaux (Château Margaux), Napa Valley Cabernet (Caymus), Vintage Champagnes (Dom Pérignon 2013), White Burgundies (Louis Latour Corton-Charlemagne), Super Tuscans (Sassicaia), and Sauternes (Château d'Yquem).
   - High-scoring critic points (Robert Parker, Wine Spectator, Decanter).
   - Sommelier tasting notes (aromas, palate profile, and finish).

4. **Multi-Faceted Wine Filtering & Instant Search**:
   - Filter by Wine Type (*Red, White, Sparkling, Rosé, Dessert*).
   - Filter by Global Terroir / Region (*France, USA, Italy, Spain, Germany, Australia, New Zealand, Portugal*).
   - Dynamic price range slider and sorting (*Featured, Price Low/High, Critic Score, Vintage*).
   - Instant real-time search across varietals, châteaux, regions, and names.

5. **Interactive AI Sommelier Match Quiz**:
   - 3-step interactive pairing wizard matching occasions, culinary dishes (steak, oysters, artisanal cheese), and flavor preferences with 1-click cellar cart addition.

6. **Interactive Sommelier Tasting Masterclass**:
   - "The Art of Tasting": 4-step ritual (See, Swirl, Sniff, Sip & Savor) with decanting, temperature, and glassware advice.

7. **The Connoisseur's Club (Wine Subscription)**:
   - 3 curated tiers (*Cellar Explorer*, *Grand Reserve Club*, and *Imperial Connoisseur*) with exclusive allocations and perks.

8. **Full-Featured Cart Drawer & Promo Engine**:
   - Free climate-controlled shipping progress meter ($200 threshold).
   - Automatic 5% Collector Case Discount on 6+ bottles.
   - Promo coupon engine (`CHEERS10` for 10% off, `VINTAGE15` for 15% off).

9. **Seamless Checkout & Order Confirmation**:
   - Encrypted checkout with legal 21+ adult signature declaration.
   - Temperature-guaranteed packaging badge.
   - Confetti celebration upon purchase with instant order reference number.

10. **Private Cellar Wishlist**:
    - Save favorites with 1-click batch transfer to cart.

---

## 🚀 How to Run

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

Then open your browser at `http://localhost:3000`.
